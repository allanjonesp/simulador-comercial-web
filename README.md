# Simulador Comercial 📊

Aplicativo web interativo, simples e responsivo para simulação comercial e planejamento financeiro.

Permite simular receitas, custos, despesas operacionais, acompanhar o atingimento de metas mensais e visualizar a composição dos gastos com gráfico proporcional.

---

## 🚀 Funcionalidades

- **Cálculo de Lucro Bruto e Líquido**: Atualização dinâmica dos saldos.
- **Margem Líquida Percentual**: Transparência no retorno sobre as vendas.
- **Acompanhamento de Metas**: Barra visual de progresso e indicador comemorativo quando a meta é superada.
- **Gráfico Proporcional de Gastos**: Divisão clara entre Custos, Despesas e Lucro.
- **Tratamento de Prejuízo**: Alerta separado para operações deficitárias, sem distorção visual de fatias negativas.
- **Totalmente Responsivo**: Funciona em computadores, tablets e smartphones.
- **100% Estático e Seguro**: Desenvolvido exclusivamente com HTML5, CSS3 e JavaScript puro, sem bibliotecas pesadas e sem coleta de dados.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Semântico e acessível)
- **CSS3** (Variáveis, Flexbox, CSS Grid e animações suaves)
- **JavaScript Vanilla** (ECMAScript moderno e API de Internacionalização `Intl`)
